# SnapMark

精緻的 macOS 截圖／錄影／標註工具。原生 Swift + SwiftUI，Universal Binary 同時支援 **Apple Silicon（M 系列）與 Intel**，介面支援**繁體中文、简体中文、English** 即時切換（免重啟）。

![platform](https://img.shields.io/badge/macOS-13.0%2B-blue) ![arch](https://img.shields.io/badge/arch-arm64%20%2B%20x86__64-purple) ![version](https://img.shields.io/badge/version-1.3.0-green)

## 功能

| 分類 | 內容 |
|---|---|
| **截圖** | 區域截圖（凍結畫面選取）、全螢幕、視窗截圖——**點一下視窗就選取、雙擊直接完成**，乾淨的視窗邊緣無陰影 |
| **原地標註（1.3）** | 選好範圍後**直接在畫面上標註**：工具列就貼在選取範圍旁，畫完按 **↩／雙擊／「完成」即拷貝＋儲存**，不會再跳出編輯器視窗要你關；⌘C 只拷貝、⌘S 存檔、⌘E 轉到完整編輯器（標註仍可編輯）、釘選、取字 |
| **移動／拉伸（1.3）** | **任何工具**都能直接拖曳已畫的標註來移動；選取後出現控制點：矩形／橢圓／筆跡 8 點拉伸（⇧ 等比）、箭頭／直線拖端點（⇧ 45°）、文字與標號拉角落等比縮放；游標會顯示可移動／可拉伸；方向鍵微調（⇧×10）、⌘D 複製一份、⌘] / ⌘[ 調整上下層、右鍵選單 |
| **復原（1.3 修正）** | 每個動作都可 ⌘Z 復原、⇧⌘Z 重做：繪製、移動、拉伸、改顏色粗細、刪除、微調（連按算一步）、文字修改（一次編輯算一步）；正在打字時 ⌘Z 先復原打字、沒得復原就復原上一個標註 |
| **可再編輯（1.3）** | 標註過的截圖存檔後，從「最近的擷取」或「在編輯器開啟圖片」再打開，**標註會以可編輯物件還原**（原始畫面保留），隨時再移動、修改、復原或「移除全部標註」回到原圖 |
| **選取體驗** | 像素放大鏡＋取色器（座標／HEX）、尺寸即時顯示、8 向調整手把、方向鍵微調（⇧×10）、三分構圖線 |
| **錄影** | 全螢幕／區域錄影（H.264 / HEVC，MP4 / MOV）、系統聲音、麥克風（macOS 15+）、可調影格率、可取消的錄前倒數、紅框指示、浮動控制列、**再按一次快捷鍵即停止**；錄影開始時自動把焦點還給原本的 App |
| **GIF** | 錄影完成後一鍵轉存 GIF |
| **編輯器** | 畫筆、螢光筆、直線、箭頭、矩形、橢圓、馬賽克／模糊、步驟標號 ①②③（刪除自動重新編號）、裁切（可再拖曳、拉邊角調整）、無限復原重做、縮放（⌘滾輪／捏合）、精準命中選取、顏色與粗細列（含自訂顏色）、**「完成」一鍵拷貝＋儲存＋關閉**（⌘↩） |
| **文字排版** | 原生文字編輯（注音／拼音友善，選字窗不被遮住）、⇧↩ 多行、拖曳外框移動、拉角落縮放字級、字體選單（常用中英字體＋全部字體、各自預覽）、粗體／斜體（無斜體字型自動合成）／底線／刪除線、左中右對齊、對比色底板、外描邊、陰影；⌘B／⌘I／⌘U、⌥⌘↑↓ 調字級 |
| **OCR 取字** | Vision 文字辨識（繁中／簡中／英文），一鍵複製；快捷鍵「框選→辨識→進剪貼簿」 |
| **釘選貼圖** | 把截圖釘在所有視窗最上層：拖曳移動、滾輪縮放、懸浮工具列、右鍵選單調不透明度、雙擊關閉 |
| **流程自動化** | 完成時自動拷貝到剪貼簿 ✓、自動存檔 ✓（PNG 含 Retina DPI）；「截圖完成後」可選：只顯示提示（預設，不跳視窗）／縮圖預覽（自動消失、點一下再標註、可直接拖進其他 App）／開編輯器／釘選；快門音效、檔名模板 `{date} {time} {seq}`；標註顏色與粗細會記住到下一次 |
| **人性化** | 首次啟動的「快速上手」視窗（權限狀態即時偵測＋一鍵重新啟動）、啟動提示 Toast、選單列常駐、編輯時才顯示 Dock 圖示、最近擷取縮圖選單、完整的中文主選單、快捷鍵衝突提示 |

## 預設快捷鍵（皆可在偏好設定自訂）

| 快捷鍵 | 功能 |
|---|---|
| ⇧⌘1 | 區域截圖 |
| ⇧⌘2 | 全螢幕截圖 |
| ⇧⌘7 | 視窗截圖 |
| ⇧⌘8 | 區域錄影（再按一次＝停止／取消倒數） |
| ⇧⌘9 | 全螢幕錄影（再按一次＝停止） |
| ⌥⇧⌘O | 框選 OCR 取字 |
| ⌥⇧⌘P | 框選釘選到螢幕 |
| ⌥⇧⌘R | 重複上次區域截圖 |

選取範圍時：**拖曳**框選、**點擊視窗**選取該視窗（雙擊直接完成）、**方向鍵** 微調、**Esc** 取消、右鍵重選。

選好之後（原地標註）：**V/P/H/L/A/R/E/T/M/B** 切換工具（再按一次或再點一次＝回到調整範圍）、**↩ / 雙擊 / ⌘↩** 完成（拷貝＋儲存）、**⌘C** 只拷貝、**⌘S** 存到資料夾、**⇧⌘S** 另存新檔、**⌘E** 轉到完整編輯器、**⌘Z / ⇧⌘Z** 復原重做、**⌫** 刪除選取的標註、**⌘D** 複製一份、**方向鍵** 微調標註（沒選標註時微調範圍）、**⌘ 拖曳** 在畫筆／螢光筆／馬賽克模式下移動既有標註。

## 安裝與權限

1. 把 `dist/SnapMark.app` 拖到「應用程式」（或直接執行）。
2. 首次啟動會開啟「快速上手」視窗並要求「**螢幕錄製**」權限：**系統設定 → 隱私權與安全性 → 螢幕錄製** → 開啟 SnapMark → 按視窗中的「重新啟動 SnapMark」。
3. 錄麥克風時會另外請求「麥克風」權限。

> **權限不會再因重建而失效。** 專案內建 `Packaging/make_dev_cert.sh`：執行一次會在獨立的鑰匙圈 `snapmark-dev.keychain-db` 建立自簽的程式碼簽署身分「SnapMark Dev」（唯一需要互動的一步是輸入登入密碼以信任憑證），之後 `build.sh` 會自動用它簽署。macOS 以簽章身分識別 App，同一身分的每次重建都算同一個 App，「螢幕錄製」授權一次即永久有效。
> 沒有這個身分時 `build.sh` 退回 ad-hoc 簽名，每次重建都得重新授權。
>
> **「系統設定裡明明開著，App 卻說沒授權」的真正原因**：macOS 的隱私記錄以 bundle ID 為鍵，並記住第一次要求時那個版本的簽章。換了簽章後，設定裡的開關仍綁著舊版本，開關開了也對不上。解法是清掉這筆記錄讓 macOS 重新登記：在歡迎視窗或選單列按「**重設權限記錄**」（等同 `tccutil reset ScreenCapture com.snapmark.app`），macOS 會再詢問一次，開啟後重新啟動即可。

> **📌 選單列圖示不見了？** 若有裝「選單列管家 / Bartender / Ice」等工具，新出現的圖示預設會被收進隱藏區，點選單列的「>」展開即可（建議設為永遠顯示）。啟動時的 Toast 會提醒你 App 已就緒。

## 從原始碼建置

```bash
./build.sh            # Universal Binary（arm64 + x86_64，只需 Xcode Command Line Tools）
./build.sh --native   # 只編譯目前架構（較快，開發用）
swift build && .build/debug/SnapMark           # 開發模式
.build/debug/SnapMark --edit ~/Desktop/a.png    # 直接用編輯器開圖
.build/debug/SnapMark --selftest /tmp/st        # 標註自我測試：模型、畫布、編輯器、原地標註（程序內合成事件，不顯示視窗、不干擾使用中的電腦），截圖輸出到 /tmp/st
```

產物：`dist/SnapMark.app`（約 5 MB，無任何第三方相依）。

## 技術架構

- **擷取**：ScreenCaptureKit（`SCScreenshotManager` / `SCStream`），macOS 13 相容備援；視窗截圖用 `desktopIndependentWindow` 取得乾淨邊緣
- **錄影**：`SCStream` → `AVAssetWriter`（H.264/HEVC + AAC，系統聲音與麥克風雙軌）
- **選取覆蓋層**：凍結畫面繪於全螢幕無邊框視窗——自家 UI 永不入鏡
- **標註畫布**：AppKit `AnnotationCanvasView`，編輯器與截圖覆蓋層共用（同一套互動、控制點、游標、就地文字編輯）；畫布與匯出共用同一套 `CGContext` 渲染器（所見即所得）；命中測試依幾何（線段距離／橢圓帶／外框環）
- **原地標註**：覆蓋層的標註以整個凍結畫面的像素為座標，選取範圍只是「視窗」——調整範圍時標註留在原處；完成時只渲染選取範圍；選到的若剛好是整個視窗，改用乾淨的視窗擷取再疊上標註
- **復原**：快照式復原堆疊；打字有獨立的 UndoManager（不汙染視窗共用的），文字編輯一次算一步、空白新文字不留步驟、連續微調合併
- **可再編輯**：存檔時以檔案內容的 SHA-256 為鍵，把原始畫面與標註清單存到 `~/Library/Application Support/SnapMark/Projects`（保留最近 200 筆）；檔案被其他 App 改過就當一般圖片開
- **快捷鍵**：Carbon `RegisterEventHotKey` 全域熱鍵；編輯器單鍵以實體 keyCode 判斷，避免輸入法干擾
- **OCR**：Vision `VNRecognizeTextRequest`
- **多語**：自製 L10n 引擎，`.strings` 資源直接放在 `Contents/Resources/*.lproj`，不依賴 SwiftPM 的 `Bundle.module`（其產生器會寫死建置機路徑）

## 專案結構

```
Sources/SnapMark/
├── main.swift / AppMain.swift      # 進入點、選單列、主選單、動作路由

├── CaptureEngine.swift             # SCK 截圖引擎
├── SelectionOverlay.swift          # 區域選取覆蓋層（放大鏡／吸附／手把／原地標註工具列）
├── RecorderEngine.swift            # SCStream → AVAssetWriter 錄影
├── RecordingHUD.swift              # 倒數、紅框、控制列、完成面板
├── GIFExporter.swift               # 影片轉 GIF
├── EditorState.swift               # 標註狀態：互動（移動／拉伸／繪製）、復原、鍵盤、匯出
├── AnnotationCanvas.swift          # 共用的 AppKit 標註畫布（控制點、游標、就地文字編輯）
├── AnnotationStyleBar.swift        # 顏色／粗細／文字快選列（編輯器與覆蓋層共用）
├── EditorView/Window.swift         # 標註編輯器視窗
├── AnnotationModel.swift           # 標註模型、文字樣式、控制點與變形、渲染器、命中測試
├── ProjectStore.swift              # 可再編輯的存檔（原始畫面＋標註）
├── CapturePreview.swift            # 截圖完成後的浮動縮圖（選用）
├── SelfTest.swift                  # --selftest 程序內自動測試
├── PinWindow.swift                 # 釘選浮動貼圖（AppKit）
├── OCRService.swift / ToastWindow / HistoryManager / HotkeyManager
├── PreferencesWindow.swift         # 偏好設定（含快捷鍵錄製器）
├── L10n.swift + Resources/*.lproj  # 三語系
└── Settings.swift                  # 使用者偏好
Packaging/                          # Info.plist、圖示產生器、自簽憑證腳本
Tools/                              # UI 自動測試工具（合成事件、視窗列表、輸入法切換）
```
